
### By Intellectual Lineage

**Empiricist Tradition**: Hume → Mill → Ayer → Stevenson → Hare → Mackie → Lewis → Quine

**Rationalist Tradition**: Descartes → Kant → Kripke → Chalmers

**Pragmatist/Naturalist Tradition**: Quine → Boyd → Railton → Dennett → Street

**Expressivist Tradition**: Ayer → Stevenson → Hare → Blackburn → Gibbard

**Realist Tradition (Metaethics)**: Moore → Parfit → Shafer-Landau → Enoch

**Constitutivist Tradition**: Kant → Korsgaard

**Ordinary Language Tradition**: Wittgenstein → Ryle [not in db] → Austin [not in db] → Williamson
