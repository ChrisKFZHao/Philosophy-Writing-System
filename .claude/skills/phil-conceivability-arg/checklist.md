# Conceivability Argument Analysis Quality Checklist

> After each conceivability argument analysis, check each item. A fully checked list indicates a high-quality analysis.

---

## Conceivability Type Classification Checks

- [ ] **Type precisely classified**: The conceivability claim is classified as prima facie, negative, positive, or ideal positive conceivability with specific textual evidence.
- [ ] **Type appropriateness assessed**: Whether the claimed type is sufficient for the argument's modal ambition is explicitly evaluated (e.g., negative conceivability cannot support metaphysical possibility without additional premises).
- [ ] **Ambiguity flagged**: If the author uses "conceivable" generically without distinguishing types, this ambiguity is flagged and explored.
- [ ] **Controversy documented**: If other philosophers dispute that the target proposition is conceivable in the claimed sense (e.g., Dennett on zombies), this is noted.

## Chain Reconstruction Checks

- [ ] **Full chain numbered**: Every inferential link is represented as L1, L2, ..., Ln with each as a single, well-formed claim evaluable independently.
- [ ] **Conceivability premise precise**: The exact proposition claimed to be conceivable is stated without ambiguity (e.g., "zombies exist" rather than "zombies are conceivable").
- [ ] **Possibility type specified**: The target modality (logical, conceptual, metaphysical, physical possibility) is identified for each link where possibility is claimed.
- [ ] **Suppressed premises surfaced**: Implicit premises needed for chain validity are made explicit (e.g., "physicalism requires necessary supervenience").
- [ ] **Alternative formulations noted**: If the argument appears in multiple forms (e.g., reductio and direct), differences affecting evaluation are documented.

## Link-by-Link Evaluation Checks

- [ ] **Core link (conceivability to possibility) evaluated**: The L1 inference receives detailed analysis addressing Kripke's necessary a posteriori challenge, the genuine conceivability question, and (if applicable) the two-dimensional semantics defense.
- [ ] **Entailment link (possibility to conclusion) evaluated**: L2 checked for logical validity, hidden premises, overclaiming, and whether the conclusion matches the strength of the possibility claim.
- [ ] **Intermediate links individually assessed**: Any additional links evaluated for validity, suppressed premises, and counterexamples.
- [ ] **Each link rated**: Every link receives a Solid / Adequate / Questionable / Broken rating with a justification paragraph.
- [ ] **Kripkean challenge applied**: For each conceivability-to-possibility link, the argument checks whether the target proposition might be a necessary a posteriori where conceivability is an illusion of ignorance.
- [ ] **Two-dimensional semantics engaged** (if applicable): For Chalmers-style arguments, the primary/secondary intension distinction and primary-to-secondary entailment conditions are specifically evaluated.

## Modal System Assessment Checks

- [ ] **S4/S5 requirements identified**: Which modal system does the argument need? Is S5 assumed without defense? Are iterated modalities (◇□P, □◇P) properly motivated?
- [ ] **Accessibility relation clarified**: The type of accessibility (logical, conceptual, metaphysical, physical) is identified. Any slides between different accessibility relations are flagged.
- [ ] **De re / De dicto distinguished**: If de re modality is involved, cross-world identity implications are noted.
- [ ] **Framework rated**: Explicit and Consistent / Implicit but Reconstructable / Ambiguous or Inconsistent / Missing.
- [ ] **Framework deficits flagged**: Missing or inconsistent modal frameworks are flagged as limits on the confidence of all ratings.

## Counterexample Detection Checks

- [ ] **Kripkean water/H2O case applied**: Where relevant, the analysis identifies whether the target proposition is structurally similar to "water is not H2O" — conceivable but impossible due to essence opacity.
- [ ] **Phenomenal concept strategy engaged** (zombie arguments): The argument checks whether phenomenal concepts present consciousness under a contingent mode of presentation (Balog, Loar, Papineau).
- [ ] **Type-B materialism addressed** (anti-physicalist arguments): For zombie and related arguments, the analysis notes whether the argument challenges only Type-A physicalism or also Type-B.
- [ ] **Completeness challenge applied**: Can the scenario be fully specified without underdescribed placeholders? Schematic descriptions flagged.

## Gap Analysis Checks

- [ ] **Weakest link identified**: The link with the lowest rating explicitly stated as the primary vulnerability.
- [ ] **Bridgeability assessed**: Each gap classified as Unbridgeable (fatal), Bridgeable (fixable with more work), or Dialectically Bridgeable (gap exists only given contested assumptions).
- [ ] **Cumulative effect evaluated**: Whether multiple weak links compound into an overall Broken chain, or gaps are independent, is assessed.
- [ ] **Gap severity ranked**: Gaps listed in order of severity with one-sentence descriptions and whether the rest of the argument survives if the gap is conceded.
- [ ] **Framework-internal vs. external distinguished**: Gaps arising from the argument's own commitments vs. general philosophical challenges are separately identified.

## Report Quality Checks

- [ ] **Executive summary present**: One-paragraph overview covering what the argument claims, what the analysis finds, and the overall rating.
- [ ] **Chain reconstruction clear**: The numbered link sequence is presented at the outset and formatted for readability.
- [ ] **Overall strength rating justified**: Rating (Strong/Medium/Weak/Broken) includes a full justification paragraph referencing specific link evaluations.
- [ ] **Dialectical fairness maintained**: The analysis presents the strongest version of the argument (including known defenses) before evaluating it.
- [ ] **Dialectical context noted**: How the argument fits into the broader debate and what the analysis implies for that debate is included.
- [ ] **Recommendations actionable**: If Weak or Broken, specific steps for strengthening are provided. If Strong or Medium, remaining vulnerabilities are identified.
- [ ] **Type-B physicalism awareness** (for zombie/anti-physicalist arguments): The analysis explicitly distinguishes whether the argument targets Type-A, Type-B, or both forms of physicalism.
