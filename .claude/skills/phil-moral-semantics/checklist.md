# Moral Semantics Analysis Quality Checklist

> After each moral semantics analysis, check each item. A fully checked list indicates a high-quality analysis.

---

## Semantic Position Classification

- [ ] **Precision to version**: Is the semantic position classified to the exact version (e.g., "Blackburn-style quasi-realist expressivism"), not merely "cognitivist" or "non-cognitivist"?
- [ ] **Evidence-supported**: Is the classification supported by specific semantic markers quoted from the text (belief-language, attitude-language, truth-predicates, expressivist vocabulary)?
- [ ] **Nearest-neighbor distinguished**: Has an explanation been given for why this specific version rather than its closest competitor?
- [ ] **Ambiguity acknowledged**: If the argument is ambiguous, has the range of compatible positions been stated along with the diagnostic question that would decide among them?
- [ ] **Practice-theory consistency**: Has the argument's actual semantic practice been checked against its explicit or implicit semantic theory for performative inconsistency?

## Frege-Geach Test Application

- [ ] **All five tests applied**: Has each of the five canonical embedding contexts been tested individually (conditional antecedents, negation, interrogatives, attitude reports, moral modus ponens)?
- [ ] **Pass/fail reasoning**: For each test, is the reasoning for the pass/fail assessment stated, not merely the verdict?
- [ ] **Practice vs. theory distinguished**: Has the analysis distinguished whether the argument's *practice* passes a test from whether its *semantic theory* can explain why?
- [ ] **Theoretical assessment for silent arguments**: If the argument is silent on a test, has the theoretical assessment been provided based on the classified position's resources?
- [ ] **Historical caveat**: If the argument predates Geach (1965) and advances non-cognitivism, has the historical caveat been added?

## Truth-Aptness Assessment

- [ ] **Truth theory diagnosed**: Has the argument's presupposed truth theory been identified (robust/correspondence, deflationary/minimalist, epistemic, coherence)?
- [ ] **Collapse risk assessed**: Has the analysis assessed whether deflationary truth collapses the cognitivism/non-cognitivism distinction in the argument?
- [ ] **Recasting identified**: If collapse risk exists, has the analysis identified whether the argument recasts the distinction in other terms (mental state type, direction of fit, explanatory role)?
- [ ] **Hybrid truth treatment**: For hybrid theories, have the truth theories for each component been separately specified?

## Thick/Thin Analysis

- [ ] **Comprehensive concept inventory**: Have all moral concepts in the argument been classified as thick or thin?
- [ ] **Dominance noted**: Has the distribution (thick-dominant, thin-dominant, or balanced) been determined and its semantic implications stated?
- [ ] **Disentanglement assessed**: Has the analysis assessed whether the thick concepts in the argument can be factored into descriptive + evaluative components?
- [ ] **Semantic challenge identified**: Has the specific challenge posed by the thick/thin distribution to the argument's semantic theory been identified?

## Expressivist Resource Adequacy

- [ ] **Compositional adequacy**: Has the ability of the semantic theory to provide a compositional semantics for arbitrarily complex moral sentences been assessed?
- [ ] **Attitude logic (expressivist)**: For expressivist positions, has the analysis checked whether the theory provides a logic of attitudes (inconsistency, entailment, validity) adequate to the argument's reasoning?
- [ ] **Motivation-semantics link (non-cognitivist)**: Has the analysis assessed whether the non-cognitive component of meaning is genuinely semantic rather than merely pragmatic?
- [ ] **Parsimony evaluation**: Has the semantic theory been evaluated for parsimony relative to its explanatory goals — neither overbuilt nor under-resourced?

## Report Quality

- [ ] **Executive summary precise**: Does the summary state the semantic position with precision and summarize Frege-Geach results?
- [ ] **Boundary conditions checked**: Has the report verified that the argument falls within scope (contains moral semantic content or deployable moral language)?
- [ ] **Implicit commitments flagged**: If the argument does not explicitly theorize its semantics, are implicit commitments analyzed with lower confidence?
- [ ] **Downstream implications noted**: Does the report note what the semantic analysis implies for downstream skills (moral realism, moral psychology)?
- [ ] **Confidence levels annotated**: Are all diagnostic judgments accompanied by confidence levels (high/medium/low)?
