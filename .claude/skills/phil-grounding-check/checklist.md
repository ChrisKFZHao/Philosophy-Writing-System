# Grounding Relation Analysis Quality Checklist

> After each grounding analysis, check each item. A fully checked list indicates a high-quality analysis.

---

## Relation Identification Checks

- [ ] **Dependence language scan complete**: All grounding, supervenience, realization, constitution, and other dependence vocabulary has been located with textual evidence.
- [ ] **Causation vs. grounding distinguished**: Every "depends on" claim has been tested for temporality — diachronic (causal) vs. synchronic (metaphysical).
- [ ] **Relation type precisely classified**: Each relation is classified as full_grounding, partial_grounding, supervenience, realization, constitution, identity, or causation, with justification.
- [ ] **No false positives**: Relations have not been invented where the text makes no dependence claim. Absence of dependence language is noted if applicable.
- [ ] **Implicit grounding flagged**: If the argument's structure implies grounding without explicit vocabulary, this is flagged with Low confidence and textual justification.

## Formal Properties Checks

- [ ] **Irreflexivity**: Each grounding relation has been checked — no entity grounds itself. Violations flagged.
- [ ] **Asymmetry**: Mutual grounding pairs checked. Any bidirectional dependence flagged as a formal violation.
- [ ] **Transitivity**: Chains of length >= 2 checked; transitivity explicitly assessed (Pass / Fail / Denied by Author).
- [ ] **Hyperintensionality**: Cases where necessarily equivalent propositions are treated as having identical grounding profiles flagged.
- [ ] **Non-monotonicity**: Cases where adding conjuncts to ground changes the grounding status flagged.
- [ ] **Supervenience-to-grounding inference checked**: If the argument moves from "A supervenes on B" to "B grounds A," this gap is explicitly flagged with explanation.

## Dependence Topology Checks

- [ ] **Fundamental entities identified**: All entities appearing as ground but never as grounded are listed as the ontological bedrock.
- [ ] **Derivative levels stratified**: All grounded entities are organized by depth (Level-1, Level-2, etc.) based on the shortest path to the fundamental.
- [ ] **Chain structure classified**: The topology is classified as foundationalist, infinitist, coherentist, or mixed.
- [ ] **Well-foundedness assessed**: Every dependence chain has been checked for termination — fully / partially / not well-founded / undetermined.
- [ ] **Topology diagram clear**: The ASCII diagram correctly represents directed edges, distinguishes relation types (solid = grounding, dashed = supervenience, dotted = realization), and is visually parseable.
- [ ] **Gaps in topology noted**: Entities whose dependence status cannot be determined from the text are explicitly listed as unresolved.

## Distinction from Causation Checks

- [ ] **Temporality test applied**: Each relation checked for temporal vs. synchronic structure. Causal relations flagged and distinguished.
- [ ] **Relata type checked**: Grounding relates facts (synchronic), causation relates events (diachronic). Misclassified relata flagged.
- [ ] **No conflation**: The analysis does not treat causal "because" as grounding "in virtue of" without explicit argument.

## Grounding Depth Checks

- [ ] **"In virtue of" test applied**: Each grounding claim assessed for whether it answers "in virtue of what does X obtain?" with genuine explanatory content.
- [ ] **Modal covariance gap flagged**: Where only supervenience is established, the gap between modal co-variance and constitutive explanation is noted.
- [ ] **Vacuous grounding checked**: Necessary truths grounding necessary truths flagged for triviality risk.
- [ ] **Over-determination analyzed**: Cases with multiple full grounds for the same entity identified and assessed (benign vs. problematic).
- [ ] **Relevance assessed**: Each grounding relation checked for ground-grounded relevance. Apparently irrelevant grounds flagged.

## Report Quality Checks

- [ ] **Executive summary present**: One-paragraph overview covering relation count, types, topology, key strengths and weaknesses.
- [ ] **Textual evidence anchored**: Every relation classification is supported by quotation or precise reference to the source text.
- [ ] **Confidence annotated**: Each relation has a High/Medium/Low confidence rating with justification.
- [ ] **Explanatory Power Score assigned**: Overall rating (Excellent / Good / Adequate / Weak / Inadequate) with justification paragraph.
- [ ] **Vulnerability analysis substantive**: The 2-4 most critical issues identified with specific reasoning and potential counterarguments.
- [ ] **Recommendations actionable**: Strengthening suggestions are specific and implementable, not merely gestural.
- [ ] **Dialectical fairness maintained**: The analysis presents the argument's dependence claims at their strongest before critiquing.
