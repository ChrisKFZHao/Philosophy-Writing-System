# Identity and Persistence Analysis Quality Checklist

> After each identity/persistence analysis, check each item. A fully checked list indicates a high-quality analysis.

---

## Sortal Identification

- [ ] **Sortal extraction**: For each identity claim, has the sortal under which identity is claimed been explicitly identified or, if implicit, inferred with justification?
- [ ] **Cross-sortal awareness**: Where identity might be claimed under different sortals (e.g., "same lump" vs. "same statue"), have the different persistence conditions been distinguished?
- [ ] **Relation discrimination**: Have numerical identity, qualitative identity, constitution, composition, genidentity, and psychological continuity been properly distinguished rather than conflated?
- [ ] **Sortal essentialism**: Does the analysis follow Wiggins's principle that identity is always identity under a sortal, and that the sortal determines persistence conditions?

## Leibniz's Law Application

- [ ] **Correct application**: Has the indiscernibility of identicals been correctly applied — if a = b, then for any property P, P(a) iff P(b)?
- [ ] **Intensional context check**: Has the analysis verified that Leibniz's Law is not mistakenly applied across intensional operators (belief, modal, quotational) where it can fail?
- [ ] **Modal variant**: In modal contexts, has the modal variant been correctly distinguished from the non-modal: if □(a = b), then any property a has necessarily, b has necessarily?
- [ ] **Property legitimacy**: Are the properties invoked in Leibniz's Law applications genuine properties (not gerrymandered, not intensional artifacts, not "identity-involving" in a question-begging way)?

## Diachronic Framework Check

- [ ] **Framework diagnosis**: Has the persistence framework (endurantism, perdurantism, exdurantism) been explicitly diagnosed with textual evidence?
- [ ] **Temporary intrinsics**: If an object changes properties over time, has the temporary intrinsics problem been considered for the endurantist interpretation?
- [ ] **Coincident objects**: If the argument involves materially coinciding objects, has the coincidence problem been identified and assessed?
- [ ] **Framework ambiguity**: If the argument's language is compatible with multiple frameworks, has this ambiguity been acknowledged and both interpretations explored?

## Cross-World Identity Analysis

- [ ] **Modal quantification**: Where modal operators are present, has it been determined whether the argument involves de re modality requiring cross-world identity tracking?
- [ ] **Framework determination**: Has the cross-world framework (transworld identity vs. counterpart theory vs. haecceitism) been diagnosed with evidence?
- [ ] **Modal strength**: Has the modal strength of identity claims been checked — are they necessary identities (standard post-Kripke), or does the argument claim/presuppose contingent identity (suspect)?
- [ ] **Rigid designation**: If proper names are involved, has the rigid designation assumption been identified and its implications for cross-world identity assessed?

## Problem Type Detection

- [ ] **Fission/fusion**: If one object becomes two (or two become one), has the fission/fusion problem been detected and the uniqueness-of-successor assumption evaluated?
- [ ] **Theseus's ship**: If gradual replacement is involved, has the Theseus problem been detected and the criterion of diachronic identity (material, formal, spatiotemporal, historical) identified?
- [ ] **Vague identity**: If borderline cases of identity appear, has Evans's argument (indeterminate identity collapses into determinate non-identity) been considered?
- [ ] **Contingent identity**: Has the argument been checked for any claim or presupposition that identity could be contingent, and if found, flagged as post-Kripke suspect?
- [ ] **Constitution/coincidence**: Has the distinction between constitution and identity been maintained, and have coincident objects been properly analyzed?
- [ ] **Arbitrary undetached parts**: If the argument involves mereology, has the AUP assumption been flagged as a substantive commitment?

## Formal Property Verification

- [ ] **Transitivity**: Where transitivity of identity is invoked, is the application valid (a = b, b = c, therefore a = c)?
- [ ] **Symmetry**: Where symmetry is invoked, is the application valid (a = b, therefore b = a)?
- [ ] **Reflexivity**: Are trivial identities (a = a) recognized as logical truths needing no substantive analysis?
- [ ] **Substitutivity**: Where substitution of identicals is invoked, is the substitution context extensional and the substitution valid?

## Framework Sensitivity

- [ ] **Sensitivity matrix**: Has the sensitivity matrix been completed, showing how each identity claim is interpreted under each persistence framework?
- [ ] **Correct classification**: Has the argument been correctly classified as robust, sensitive_but_defensible, or framework_dependent?
- [ ] **Dialectical impact**: If framework_dependent, has the dialectical vulnerability been explained — an opponent can reject the framework and thereby dismiss the argument?
- [ ] **Translation feasibility**: If framework_dependent, has it been assessed whether the argument can be translated into a framework-independent form?

## Report Completeness

- [ ] **Identity claims inventory**: Does the report include all identity claims with statement, logical form, sortal, location, and role?
- [ ] **Problem severity**: For each detected identity problem, is the severity assessed relative to the argument's structure (fatal, significant, minor)?
- [ ] **Response inventory**: For each problem, are available philosophical responses identified?
- [ ] **Overall assessment**: Does the report conclude with a summary statement about how identity/persistence considerations affect the argument's strength?

## Boundary Handling

- [ ] **No identity claims**: If no identity claims are present, has "No identity claims detected; persistence analysis not applicable" been reported with explanation?
- [ ] **Purely extensional**: If the argument is purely extensional and synchronic, have cross-world and cross-time analyses been appropriately skipped with explanation?
- [ ] **Personal identity**: If the argument concerns personal identity, have the specific personal identity frameworks (psychological continuity, biological, narrative, simple) been included?
- [ ] **Trivial identities**: Have logical truths of the form a = a been recognized as trivial and not over-analyzed, with the boundary condition triggered?
