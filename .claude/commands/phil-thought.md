# /phil-thought

Loads the `phil-thought-experiment` skill to analyze thought experiments.

## Usage

```
/phil-thought <thought experiment description or text passage>
```

## Behavior

1. Scenario decomposition (five elements)
2. Intuition-triggering mechanism analysis
3. Conclusion derivation path tracing
4. Presupposition audit
5. Alternative case testing
6. Six-dimension effectiveness assessment
7. Outputs a thought experiment analysis report
