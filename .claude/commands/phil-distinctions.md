# /phil-distinctions

Loads the `phil-distinction-track` skill to track conceptual distinctions in text.

## Usage

```
/phil-distinctions <text>
```

## Behavior

1. Scans the text for all conceptual distinctions and contrasts
2. Indexes distinctions (type / exhaustiveness / mutual exclusivity)
3. Analyzes the argumentative function of each distinction
4. Checks for consistency across distinctions (drift detection)
5. Maps the network of relationships among distinctions
6. Detects missing critical distinctions
7. Outputs a distinction tracking report
