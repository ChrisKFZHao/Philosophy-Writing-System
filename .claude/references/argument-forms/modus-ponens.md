# Modus Ponens (Affirming the Antecedent)

## Form

```
[1] P → Q    (If P, then Q)
[2] P        (P is true)
∴ [3] Q      (Therefore, Q is true)
```

## Description

Modus ponens is one of the most fundamental inference forms in deductive argumentation. From a conditional statement and its antecedent, one derives the consequent. This form is **valid** -- if the premises are true, the conclusion is necessarily true.

## Typical Variants

### Hypothetical Syllogism

```
[1] P → Q
[2] Q → R
∴ [3] P → R
```

### Chain Argument

```
[1] P → Q
[2] P
[3] Q → R
∴ [4] R
```

## Common Misuses in Philosophical Analysis

- **Fallacy of Affirming the Consequent**: `P → Q, Q ∴ P` -- **invalid**
- **Fallacy of Denying the Antecedent**: `P → Q, ¬P ∴ ¬Q` -- **invalid**
