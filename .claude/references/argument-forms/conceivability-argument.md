# Conceivability Argument

## Form

### Core Structure

```
[1] P is (ideally) conceivable
[2] If P is ideally conceivable, then P is metaphysically possible
∴ [3] P is metaphysically possible
[4] [Further steps from possibility to the target conclusion]
```

### The Zombie Argument (Chalmers, 1996) — Canonical Application

```
[1] Zombies are ideally conceivable
      (A zombie: a molecule-for-molecule duplicate of a conscious being, lacking phenomenal consciousness)
[2] If zombies are ideally conceivable, then zombies are metaphysically possible
∴ [3] Zombies are metaphysically possible
[4] If zombies are metaphysically possible, then physicalism is false
      (Physicalism entails that all facts supervene on physical facts; zombie worlds have identical physical facts but different phenomenal facts)
∴ [5] Physicalism is false
```

### Two-Dimensional Semantics Defense (Chalmers, 2009)

```
[1] S is ideally negatively conceivable   (S is not ruled out a priori)
[2] If S is ideally negatively conceivable, then S is primarily possible (1-possible)
[3] If S is primarily possible, then, when S involves no a posteriori necessity, S is secondarily possible (2-possible)
∴ [4] S is metaphysically possible
```

This framework handles Kripkean a posteriori necessities (water ≠ H₂O is 1-conceivable but not 2-possible) by distinguishing two dimensions of meaning.

## Distinctive Features in Philosophical Analysis

1. **The conceivability-possibility link**: The argument's soundness depends entirely on premise [2] — the inference from conceivability to possibility. This is the central point of contention.

2. **Gradations of conceivability**: Not all conceivings are equal. The literature distinguishes:
   - **Prima facie conceivability**: At first glance, seems coherent.
   - **Negative conceivability**: Not ruled out a priori. (Cannot detect a contradiction by pure reason.)
   - **Positive conceivability**: Can be coherently imagined in rich detail.
   - **Ideal conceivability**: Would be conceivable on ideal rational reflection, free of cognitive limitations.

3. **Modal-epistemic bridge**: Conceivability arguments attempt to bridge an epistemological starting point (what we can conceive) to a metaphysical conclusion (what is possible). This bridge is what Hume first challenged and what contemporary modal epistemology interrogates.

4. **Role of S5**: In S5 modal logic, if `◇P` at any world, then `□◇P` at all worlds. This means that any successful conceivability argument establishes not merely that P happens to be possible, but that P is necessarily possible — a stronger claim that some critics exploit.

## Evaluation Criteria

1. **Which grade of conceivability is claimed?** — Prima facie conceivability is too weak; ideal conceivability is the gold standard but also the most demanding to establish. Reconstructors must identify which grade is operative.

2. **Is the case subject to Kripkean a posteriori necessity?** — The conceivability of "water is not H₂O" does not entail its possibility, because the identity is necessary a posteriori. Check whether the target proposition involves such identities.

3. **Does the argument survive the "gap" challenge?** — Yablo (1993) and others argue that even ideal conceivability underdetermines metaphysical possibility: there may be necessary truths inaccessible even to ideal reasoners.

4. **Is the further step from possibility to the conclusion valid?** — In the zombie case, step [4] is contested: some physicalists deny that the possibility of zombies entails the falsity of physicalism (e.g., type-B materialists who accept the epistemic gap but deny the ontological gap).

## Famous Cases

| Argument | Proponent | What is Conceived | Target Conclusion |
|----------|-----------|-------------------|-------------------|
| Zombie Argument | Chalmers (1996) | Phenomenal zombies | Physicalism is false |
| Modal Ontological Argument | Plantinga (1974) | A maximally great being | God exists |
| Disembodied Existence | Descartes (1641) | Mind existing without body | Mind and body are distinct substances |
| Inverted Spectrum | Locke (1689) | Color qualia inverted | Color experience is not reducible to physical states |
| The Knowledge Argument | Jackson (1982) | Mary knowing all physical facts | Physicalism is incomplete (related to conceivability) |

## Reconstruction Notes

- When reconstructing a conceivability argument, **annotate which grade of conceivability** the author appeals to. Use `[C-prima]`, `[C-neg]`, `[C-pos]`, or `[C-ideal]` as annotations.
- Mark the **modal step** explicitly with `[CP]` (conceivability-to-possibility premise) so it can be targeted for critique.
- In two-dimensionalist reconstructions, indicate whether the argument tracks **primary** or **secondary** possibility.
- Watch for **modal scope ambiguity**: does the argument claim `◇P` (P is possibly true) or `∃w(P is true at w)` (there is a world where P is true)? These are equivalent in standard semantics but the latter formulation can obscure hidden assumptions about cross-world identity.
- The "ideal" qualifier is doing heavy lifting — many arguments fail not because conceivability does not entail possibility, but because the conceiving in question falls short of ideal.
