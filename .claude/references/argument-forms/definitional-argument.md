# Definitional Argument

## Form

### Definitional Syllogism

```
[1] By definition, X = Y (or X possesses property F)
[2] Some particular thing a falls under X
∴ [3] a possesses property F
```

Or the negative form:

```
[1] By definition, X possesses property F
[2] Some particular thing a does not possess property F
∴ [3] a is not X
```

### Definitional Equivalence Inference

```
[1] ∀x (X(x) ↔ φ(x))    (The definition of X is equivalent to condition φ)
[2] φ(a)                 (Object a satisfies condition φ)
∴ [3] X(a)               (Therefore, a is X)
```

## Description

Definitional arguments are common in everyday philosophical argumentation. The **structure** of the argument is deductively valid, but its **persuasiveness** depends entirely on (1) the adequacy of the definition, and (2) whether the object genuinely falls within the scope of the definition.

The crux of a definitional argument lies not in the inferential form but in the **legitimacy of the definition** -- this is a core concern of philosophical analysis.

## Evaluation Criteria

| Dimension | Guiding Question |
|-----------|------------------|
| **Non-circularity** | Does the definition implicitly contain the conclusion? (Is there a question-begging element?) |
| **Adequate scope** | Is the definition too broad (including things that should not fall under X) or too narrow (excluding things that should)? |
| **Theoretical neutrality** | Does the definition presuppose a particular theoretical stance? |
| **Relation to ordinary usage** | If it is a stipulative definition, does the author clearly acknowledge its departure from ordinary usage? |

## Special Concerns in Philosophy

Definitional arguments frequently overlap with conceptual analysis (`phil-conceptual-analysis`). The key distinction:
- **Definitional argument** concerns: given that a certain definition holds, whether the subsequent inference is valid.
- **Conceptual analysis** concerns: whether the definition itself is correct (testing necessary / sufficient conditions).

## Reconstruction Notes

- Confirm whether the "definition" is explicit or implicit in the original text -- if implicit, annotate it as [IP].
- If the definition clearly presupposes a particular theoretical stance, note this presupposition when reconstructing charitably.
- If the definition has a contested dimension (e.g., "freedom = absence of coercion by others"), annotate the missing dimension (e.g., "freedom = absence of any external obstacle").
