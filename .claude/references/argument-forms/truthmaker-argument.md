# Truthmaker Argument

## Form

### Core Structure — Truthmaker Maximalism

```
[1] For every true proposition P, there exists some entity E that makes P true
    (Truthmaker Principle; Truthmaker Maximalism)
[2] Proposition Q is true
[3] Q requires an entity of type T as truthmaker (no entity of another type suffices)
∴ [4] Entities of type T exist (ontological commitment via truthmaking)
```

### Armstrong's Truthmaker Argument for States of Affairs

```
[1] Every contingent truth requires a truthmaker
[2] The proposition <a is F> is a contingent truth
[3] The truthmaker for <a is F> cannot be a alone, nor F alone, nor the mereological
    sum a+F — it must be a's being F (a state of affairs)
∴ [4] States of affairs exist as fundamental ontological categories
```

### Truthmaker Argument for Presentism (or Against It)

```
[1] Present-tense propositions about the past are true (e.g., <Socrates drank hemlock>)
[2] Every true proposition requires a truthmaker
[3] If only present entities exist (presentism), there is no truthmaker for past-tense
    truths
∴ [4] Either: reject presentism, or reject truthmaker maximalism for past-tense truths
```

## Variants

### Truthmaker Necessitarianism

```
[1] If E makes P true, then necessarily: if E exists, P is true
This is the strictest version — the truthmaker necessitates the truth of the proposition.
```

### Truthmaker Non-Necessitarianism

```
[1] If E makes P true, E's existence is sufficient for P's truth in the actual
    circumstances, but may not necessitate it across all possible worlds
```

## Distinctive Features

1. **Ontological commitment via semantics**: Unlike Quinean criterion of ontological commitment (to be is to be the value of a bound variable), truthmaker theory determines ontology through the grounding of truth: to be is to be a truthmaker for some true proposition.

2. **The truthmaker gap problem**: Certain kinds of truths appear to resist truthmaker analysis:
   - **Negative truths**: What makes <there are no unicorns> true? There is no entity that is the absence of unicorns.
   - **Universal generalizations**: What makes <all ravens are black> true? Every individual raven's being black?
   - **Modal truths**: What makes <possibly, there are talking donkeys> true?

3. **Relation to grounding**: Truthmaking is a species of metaphysical grounding — the truth of a proposition is grounded in the existence of its truthmaker. Truthmaker theory is thus a specific application of the broader grounding framework.

4. **Truthmaker vs. Truthmaker Maximalism**: One can accept that some truths have truthmakers without accepting that all truths do (Maximalism). The truthmaker gap problem primarily threatens Maximalism, not the weaker thesis.

## Evaluation Criteria

1. **The truthmaker gap**: Can the truthmaker theorist provide plausible truthmakers for negative truths, universal generalizations, and modal truths without inflating ontology unacceptably?

2. **The necessity of truthmaking**: Is the relation between truthmaker and truth necessary (necessitarianism) or merely sufficient in circumstance (non-necessitarianism)? Each has costs.

3. **Cheating**: Does positing "negative facts," "totality facts," or "the world as a whole" as truthmakers amount to ontological cheating — creating entities tailor-made to fill the gap?

## Reconstruction Notes

- The key implicit premise is often left unstated: `[IP] The only possible truthmaker for Q is of type T`. The argument is only as strong as this uniqueness claim.
- Distinguish **truthmaking** (the relation between an entity and a true proposition) from **truth conditions** (the conditions under which a proposition is true). The latter is semantic; the former is metaphysical.
- When reconstructing a truthmaker argument, identify whether the author endorses **Maximalism** or only a restricted truthmaker principle. The scope of the principle determines which ontological commitments are forced.
- Beware of conflating **explanation** with **truthmaking**: explaining why a proposition is true and identifying what makes it true are distinct enterprises.
