# Recombination Argument (Lewis)

## Form

### Core Structure

```
[1] For any set of spatiotemporally isolated possible individuals, there is a possible
    world containing exactly those individuals
[2] The principle of recombination: any entities that can exist separately can exist
    together, and any entities that can exist together can exist separately
[3] The actual world contains many spatiotemporally isolated individuals
[4] If an individual exists in the actual world, that individual (or a duplicate
    thereof) can exist in other possible worlds
∴ [5] There exists a vast plurality of possible worlds, each a recombination of
    actual-world elements
```

### Arguments for Modal Realism (Compact)

```
[1] Possible worlds discourse is indispensable for analyzing modality, counterfactuals,
    and propositional content
[2] Possible worlds must be taken as ontologically real entities, not mere linguistic
    fictions or abstract representations
[3] The best theory of what possible worlds are is Lewisian concretism: possible
    worlds are maximal spatiotemporally interrelated sums of individuals
∴ [4] Concrete possible worlds exist (Modal Realism)
```

## Distinctive Features

1. **Recombination as a generative principle**: Unlike logical modalities which are generated by consistency with axioms, recombination generates possibilities combinatorially from actual-world building blocks. This ties modal truth to actual-world ontology rather than to logical space alone.

2. **Humean denial of necessary connections**: The recombination principle requires that there be no necessary connections between distinct existences. Lewis inherits this Humean commitment: any two distinct entities can exist without the other. Without this assumption, the recombination argument cannot generate the full plenitude of possible worlds.

3. **Combinatorialism (Armstrong)**: Armstrong develops a related view — combinatorialism — according to which possibilities are recombinations of fundamental particulars and universals from the actual world. This differs from Lewis in treating possible worlds as fictions or abstractions rather than concrete entities.

4. **Indexical actuality**: Lewis holds that "actual" is an indexical term: every world is actual to its inhabitants. The recombination argument does not privilege the actual world except as the source of the raw materials for recombination.

## Evaluation Criteria

Evaluating a recombination argument requires examining:

1. **The recombination principle itself**: Is there any principled limit to recombination? Do some recombinations yield impossibilities? (E.g., can one recombine a necessarily existing entity with a world in which it does not exist?)

2. **The spatiotemporal isolation premise**: Are actual-world individuals genuinely spatiotemporally isolated in the sense required? Does causal isolation suffice?

3. **The ontological cost**: Even if the recombination argument is valid, does it justify the extreme ontological cost of Lewisian modal realism? The argument may be valid but its premises may be rejected on grounds of parsimony.

4. **Completeness**: Does recombination generate all and only the genuine possibilities? Armstrong worries about "alien" properties not instantiated in the actual world — recombination cannot generate these.

## Famous Cases

| Argument | Proponent | Recombination Target | Key Move |
|----------|-----------|---------------------|----------|
| Plurality of Worlds | Lewis (1986) | Spatiotemporally isolated individuals | Recombination → concrete possible worlds |
| Combinatorial Theory | Armstrong (1989) | Fundamental particulars + universals | Recombination → abstract possible worlds |
| Humean Supervenience | Lewis (1986) | Local matters of particular fact | Recombination → all possibilities supervene on local facts |
| Patchwork Principle | Benardete (1964) | Spatial/temporal regions | Any set of possible spatiotemporal patches can coexist |

## Reconstruction Notes

- The key implicit premise in most recombination arguments is the **Humean denial of necessary connections**: `[IP] There are no necessary connections between distinct existences`. Without this premise, recombination is not guaranteed to produce genuine possibilities.
- Distinguish **combinatorial** recombination (rearranging actual-world elements) from **plenitudinous** recombination (generating all possible worlds, including those with alien properties).
- When reconstructing, check whether the argument targets **concrete** modal realism (Lewis) or **ersatz** modal realism (Armstrong, Plantinga). The recombination structure is shared but the ontological interpretation differs.
- The strength of a recombination argument depends on the **principle of recombination** — is it a metaphysical principle, a conceptual truth, or a methodological heuristic?
