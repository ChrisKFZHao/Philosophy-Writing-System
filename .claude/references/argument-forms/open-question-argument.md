# Open Question Argument (Moore)

## Form

### Core Structure

```
[1] Suppose "good" means the same as natural property N (e.g., "pleasurable")
[2] If "good" = N analytically, then the question "Is X that is N good?" should be closed
    (truistic — the answer is "yes" by definition alone, and anyone who understands the terms
    should immediately recognize the truth)
[3] For any natural property N, "Is X that is N good?" remains an open question
    (a competent speaker can understand the question and meaningfully doubt the answer)
∴ [4] "Good" ≠ any natural property (the naturalistic fallacy: identifying goodness with a
    natural property is always a mistake)
∴ [5] Goodness is a sui generis non-natural property (Moore's non-naturalism)
```

The argument proceeds by **universal generalization**: it tests candidate natural properties one by one, and finding that each leaves the question open, concludes that no natural property can be identical to goodness. The argument does not depend on any particular natural property N — it claims that the open question arises for *every* candidate.

## Distinctive Features

1. **Semantic test as metaphysical lever**: The argument uses a purely semantic test (the open/closed question distinction) to establish a metaphysical conclusion (that goodness is non-natural). This makes it a rare bridge between philosophy of language and metaphysics.

2. **Contrast with the naturalistic fallacy**: The open question argument is often conflated with the naturalistic fallacy, but they are distinct. The naturalistic fallacy is the mistake of identifying goodness with a natural property; the open question argument is the *argument* that demonstrates why such identification is always a mistake.

3. **Analyticity-dependent**: The argument presupposes a sharp analytic/synthetic distinction and a transparency thesis about meaning — that competent speakers have privileged access to the sameness or difference of meanings. Quinean and Kripkean critiques target precisely these presuppositions.

4. **Universal quantifier over natural properties**: A key structural feature is the claim that the open question persists *for all* natural properties. Even if some natural properties fail, others might succeed — but Moore denies this possibility in advance.

## Evaluation Criteria / Objections

| Objection | Description |
|-----------|-------------|
| **Paradox of analysis** | If a conceptual analysis is correct, the analysans and analysandum are identical in meaning, so the question "Is X that is A necessarily B?" should be closed — but no interesting analysis would then be informative. The fact that the question feels "open" does not entail that the identity is false; it may entail that non-trivial identities generate this illusion. |
| **Synthetic identities** | The argument assumes that all true identity statements must be analytic. But "water = H₂O" is a synthetic identity true a posteriori — the question "Is this water H₂O?" was open until empirical investigation closed it. If value identities can be synthetic, the open question argument collapses. |
| **The "that depends" response** | For many natural properties N, the question "Is X that is N good?" is not straightforwardly open or closed — the answer depends on context, on what else is true of X, or on further specification. The binary open/closed distinction may be too crude. |
| **Idealized vs. actual speakers** | The test uses the intuitions of competent but non-expert speakers. But if moral knowledge requires special expertise or idealization (as some realists claim), actual speaker intuitions are the wrong test. |
| **The "good" as a functional concept** | If "good" is defined functionally (e.g., what fulfills the function of an organism), then the question for certain N may indeed be closed. Moore's argument works only against purely descriptive definitions, not functional ones. |

## Famous Cases

| Case | Proponent | Natural Property N | Open Question Form |
|------|-----------|-------------------|---------------------|
| Classical hedonism | Bentham, Mill | Pleasure / absence of pain | "Is pleasure good?" |
| Evolutionary ethics | Spencer | What is more evolved | "Is the more evolved better?" |
| Divine command theory | Various | What God commands | "Is what God commands good?" (Euthyphro's precursor) |
| Desire-satisfaction | Various | What satisfies desires | "Is satisfying a desire good?" |
| Cornell realism | Boyd, Brink | Homeostatic property clusters | "Is what promotes human flourishing (in the homeostatic cluster sense) good?" — if this is a synthetic identity, the open question does not refute it |

## Reconstruction Notes

- Distinguish the **open question argument** from Moore's broader **non-naturalism**. The argument supports non-naturalism but does not entail it — one could accept [4] (no natural property definition works) while remaining a non-cognitivist rather than a non-naturalist.
- The argument is **not** an argument for moral realism; it is an argument against ethical naturalism. Non-cognitivists (Ayer, Stevenson, Hare) exploited the open question to support their own views — they agree that "good" is indefinable, but conclude that it is not a property at all.
- The structural parallel with the **Euthyphro dilemma** should be noted: both argue that identifying moral properties with natural/divine properties generates an inescapable question.
- In reconstruction, the implicit premise is often: `[IP] Semantic competence with "good" gives one access to its meaning, and identity of meaning is transparent to competent speakers.`
