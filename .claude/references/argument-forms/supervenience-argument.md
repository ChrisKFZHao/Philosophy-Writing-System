# Supervenience Argument

## Form

### Core Structure — Global Supervenience Argument

```
[1] A-properties globally supervene on B-properties
      (For any worlds w₁, w₂: if w₁ and w₂ have the same B-properties, then they have the same A-properties)
[2] There is no A-difference without some B-difference
[3] B-properties are [physical / natural / non-normative / non-modal] (the designated base)
[4] If A supervenes on B with B as the supervenience base, then A is nothing "over and above" B  [CONTENTIOUS]
∴ [5] A-facts are determined by / reducible to / explicable in terms of B-facts
```

### Weak Supervenience (Kim)

```
[1] Necessarily: if any object x in a world w has A-property F, then x has some B-property G such that any object y in w with G also has F
[2] This is intra-world only — no cross-world constraint
```

### Strong Supervenience (Kim)

```
[1] Necessarily: if any object x in any world w has A-property F, then x has some B-property G such that, necessarily, any object y in any world w' with G also has F
[2] This imposes a cross-world modal constraint
```

### Humean Supervenience (Lewis)

```
[1] All facts about the world supervene on the spatiotemporal distribution of local, perfectly natural properties and relations
[2] No necessary connections between distinct existences
[3] The mosaic of local qualities determines everything
```

## Distinctive Features in Philosophical Analysis

1. **Supervenience as a minimal commitment**: Supervenience is often claimed to be a "minimal" physicalist thesis — it asserts determination without reduction, allowing non-reductive physicalism. This minimality is also its vulnerability: some argue that bare supervenience is too weak to capture physicalism's ontological import.

2. **Modal strength**: Supervenience comes in multiple strengths, and the choice of strength dramatically affects what follows. Global supervenience is weaker than strong supervenience in some formulations; strong supervenience entails global, but the converse is controversial.

3. **The "nothing over and above" move**: Step [4] is the critical — and most contested — premise. Supervenience alone is a modal covariation thesis; the further claim that it yields determination, reduction, or explanation requires additional metaphysical argument. This is known as the "explanatory gap" for supervenience.

4. **Blackburn's challenge (for moral supervenience)**: Why do moral properties supervene on natural properties? The supervenience itself calls for explanation. If the supervenience is a brute modal fact, it conflicts with the Humean ban on necessary connections between distinct existences. If it is explained by reduction, then moral properties are natural — but this has its own costs.

## Evaluation Criteria

1. **Which strength of supervenience is asserted?** — Weak, strong, or global? The distinction matters for cross-world inferences and for whether the supervenience relation supports the intended conclusion.

2. **Is the supervenience claim plausible?** — Are there counterexamples to the no-A-difference-without-B-difference claim? (E.g., aesthetic twins, moral twins, qualia inversion.)

3. **Does the argument bridge from supervenience to explanation?** — Supervenience alone is a descriptive claim about covariation. Does the argument provide an independent reason to move from "[A covaries with B]" to "[B explains A]"?

4. **Is the supervenience base "kosher"?** — The base properties must be independent, well-understood, and non-disjunctive. If the base is gerrymandered, the supervenience claim may be trivial.

5. **Blackburn's challenge**: Does the argument account for *why* the supervenience relation holds, or does it treat it as brute? Brute supervenience is metaphysically suspect for many theorists.

## Famous Cases

| Argument | Proponent(s) | Supervenience Claim | Target Conclusion |
|----------|-------------|---------------------|-------------------|
| Moral Supervenience | Hare (1952), Blackburn (1971) | Moral properties supervene on natural properties | Moral realism / irrealism debate |
| Humean Supervenience | Lewis (1986) | All facts supervene on the Humean mosaic | Reductive physicalism; regularity theory of laws |
| Aesthetic Supervenience | Sibley (1959) | Aesthetic properties supervene on non-aesthetic | Objectivity of aesthetic judgment |
| Mental-Physical Supervenience | Kim (1984, 1993) | Mental states supervene on physical states | Non-reductive physicalism |
| Global Supervenience and Physicalism | Haugeland (1982), Hellman & Thompson (1975) | All facts globally supervene on physical facts | Physicalism defined via supervenience |

## Reconstruction Notes

- Annotate the strength of the supervenience relation: `[S-weak]`, `[S-strong]`, `[S-global]`, or `[S-Humean]`.
- The key inferential gap is usually **from supervenience to explanation/reduction/determination**. Mark this as `[SG]` (supervenience gap) so it can be isolated for critique.
- When the argument involves moral supervenience, flag Blackburn's explanatory-demand as an implicit burden: `[BC]` (Blackburn's challenge).
- Distinguish **individual supervenience** (property of objects) from **global supervenience** (property of worlds) — the logic of the two differs.
- In evaluation, test whether the supervenience relation is **strong enough** to support the intended conclusion but not so strong as to be implausible. Many supervenience arguments fail by asserting a relation that is either too weak to do the needed work, or too strong to be defensible.
