# Dilemma

## Form

### Basic Dilemma

```
[1] P ∨ Q          (P or Q)
[2] P → R          (If P, then R)
[3] Q → R          (If Q, then R)
∴ [4] R            (Therefore, R)
```

This is the **Constructive Dilemma**, a valid deductive form.

### Destructive Dilemma

```
[1] P ∨ Q
[2] P → R
[3] Q → S
[4] ¬R ∨ ¬S
∴ [5] ¬P ∨ ¬Q     or equivalently: ¬(P ∧ Q)
```

## Special Forms in Philosophical Analysis

### The Fork

```
[1] Either P or Q
[2] If P, then R (R is unacceptable)
[3] If Q, then S (S is unacceptable)
∴ [4] Neither P nor Q → need a new option
```

Corresponding to:

```
[1] P ∨ Q
[2] P → ¬R  (R is desired)
[3] Q → ¬R
∴ [4] No option attains R → search for new options
This differs from the standard dilemma in not being a conclusive deduction, but rather opening up exploratory space.
```

## Evaluation Criteria

Evaluating a dilemma argument requires examining three dimensions:

1. **The disjunctive premise**: Does P ∨ Q exhaust all possibilities? (There is typically a hidden third possibility.)
2. **The conditional premises**: Does each conditional hold? Are there counterexamples to P → R?
3. **The acceptability of the conclusion**: If R is indeed acceptable, the dilemma stands; if R can be evaded ("escaping between the horns"), the dilemma fails.

## Famous Cases in Philosophical Analysis

- **Euthyphro Dilemma**: Is the pious loved by the gods because it is pious, or pious because it is loved by the gods?
- **The Empiricist's Predicament**: All knowledge comes from experience / Mathematical knowledge does not come from experience / So is mathematical knowledge possible?
- **The Determinism Dilemma**: Determinism → no freedom; Indeterminism → randomness / no freedom; both lead to no freedom.
- **The Erinyes Dilemma** (against rights-based political philosophy): Some have rights → exclusivity; Everyone has rights → unsatisfiable.

## Reconstruction Notes

- Critique of dilemma arguments typically focuses on the **third possibility** ("escaping between the horns").
- When reconstructing, explicitly mark whether the disjunctive premise is exhaustive.
- If the author claims to have constructed a dilemma but provides only two options, check whether there are unconsidered alternatives.
