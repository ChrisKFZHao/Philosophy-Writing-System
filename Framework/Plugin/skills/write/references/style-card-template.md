# Style card template

Copy this file to `Private/Style/style-card.md` and fill it in. The composer and editor read the card on every section, so keep it under about 1,500 characters. Rules come from three sources: the author's own Chinese writing, chosen exemplars, and edits the author confirmed in `style-ledger.md`.

```
# 风格卡

读者：<谁会读这篇论文，他们已经知道什么>
语气：<例如：平实、确定、不端架子>

句子：
- <长短、节奏、一句一个判断；推理的前提和结论可以同句等>

句与句、段与段：
- <句间关系要写出来、不写成断言清单；每段一件事，段首直接做；节间衔接不用套路等>

用词：
- 偏好：<…>
- 避免：<…>

定义与对比：
- <先说是什么，再说不是什么等>

引用：（作者，年份）

范文：Private/Style/exemplars/ 中的 <文件名>：<学它的什么>

来自作者修改的规则：
- <日期> <规则>（来源：style-ledger.md）
```
