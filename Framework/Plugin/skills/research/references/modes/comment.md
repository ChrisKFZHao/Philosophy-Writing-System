# Mode contract: comment

Read-only deep qualitative commentary on an argument or text, focused on **argumentative detail and conceptual clarification**. No bibliography or project mutation.

## Usage

```
phil:research comment <argument or text>
```

## Positioning

- vs `evaluate`: comment is deep qualitative analysis of argumentative detail; evaluate is the preplanned baseline-plus-dimensions critique.
- vs `phil:review`: comment targets others' arguments; review is whole-paper peer review of one's own manuscript.

## Dimensions

1. **Unstated assumptions** — `method.argument.premise-detect`
2. **Alternative readings** — model judgment, cross-checked against the source text
3. **Missing distinctions** — `method.concept.distinction-track`
4. **Undefended steps** — model judgment on inferential links
5. **Hidden commitments** — `method.metaphysics.ontological-commitment` (ontological/semantic) and `method.dialectic.methodology` (methodological)
6. **Dialectical blind spots** — `method.dialectic.dialectical-map`

Load only the methods a live reading of the text actually selects; an absent dimension is reported as such, not padded.

## Output

Standard commentary report in Chinese: (1) overall impression; (2) dimension-by-dimension analysis; (3) constructive suggestions; (4) directions for further inquiry.
