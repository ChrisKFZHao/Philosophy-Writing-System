# Charity Check Quality Checklist

> After each charity audit, check each item. A fully checked list indicates a high-quality charity audit report.

---

## Strongest Version Construction

- [ ] **Strength comparison performed**: For each premise, the reconstructed version has been compared against the original text to determine whether a stronger defensible interpretation exists — per Detection A of the Source-Based Strength Assessment.
- [ ] **Stronger alternative sought where ambiguity exists**: If the original text contains ambiguity or underdeveloped passages, the reconstruction is checked for whether it selected the stronger interpretation or defaulted to the weaker one.
- [ ] **Qualified readings preserved**: Original-text qualifiers ("usually," "under certain circumstances," "tends to") are checked — the reconstruction does not universalize a qualified claim into an absolute one.
- [ ] **Charity not forced into fiction**: Per the Boundary Conditions, the Principle of Charity does not require turning a bad argument into a good one — if the original text's fundamental defect cannot be remedied through charitable revision, this is honestly stated.
- [ ] **Premise-level charity rated**: Each premise receives a charity rating (Sufficiently Charitable / Under-charitable / Requires Re-evaluation) with justification grounded in original-text evidence.

## Fidelity Check

- [ ] **Evidence-Driven Principle satisfied**: Every judgment of under-charitability is supported by original-text evidence — charity cannot be denied based on intuition or preference, per the Quality Criteria.
- [ ] **Author-Tendency Principle applied**: If the author has more precise formulations in other texts, those formulations are used as the charitable baseline — the reconstruction is checked for consistency with the author's broader corpus.
- [ ] **Author's own refutations respected**: If the author has elsewhere explicitly denied a premise as currently reconstructed, the Principle of Charity requires adopting an interpretation consistent with the author's overall position — this is checked.
- [ ] **Interpretive distance annotated**: Where the reconstructed version departs from the original text, the distance is annotated (Close / Moderate / Significant) — per the Distance Transparency Principle.
- [ ] **Unimprovable reconstruction recognized**: If the reconstructed version is already the strongest reasonable version, the audit outputs "Pass" — no changes forced, per the Boundary Conditions.

## Oversimplification Detection

- [ ] **Nuanced claims preserved**: The reconstruction does not flatten graded, context-sensitive claims into binary yes/no assertions — gradations and qualifications are preserved or flagged as lost.
- [ ] **Multi-premise arguments not collapsed**: If the original text presents a multi-step chain of reasoning, the reconstruction does not collapse it into a single oversimplified premise — structural complexity is preserved.
- [ ] **Conflation avoided**: Distinct claims that should be separated into multiple sub-arguments are checked — the reconstruction does not conflate them into a single premise for convenience.
- [ ] **Context-sensitive terms respected**: Terms whose meaning shifts with context (e.g., "rational," "free," "good") are not treated as if they carry a single univocal meaning across all premises.

## Distortion Detection

- [ ] **Claims not twisted into rejected positions**: Each reconstructed premise is checked — would the original author reasonably accept this formulation? If not, the reconstruction has introduced distortion.
- [ ] **Straw-manning avoided**: The reconstruction does not weaken the argument by attributing to it a position the author would reject, then implicitly or explicitly criticizing that weaker position.
- [ ] **Implicit qualifiers not stripped**: Where the original text implicitly carries qualifications (e.g., "under normal conditions"), the reconstruction does not strip them — this is checked via Detection B of the Source-Based Strength Assessment.
- [ ] **Excessively vague original text handled honestly**: If the original text is too vague to determine whether distortion has occurred, this uncertainty is noted rather than the reconstruction being forced into an arbitrary reading.

## Alternative Readings

- [ ] **Multiple reasonable interpretations explored**: For each premise judged under-charitable, at least two alternative readings are generated — a weak alternative (closer to the original text) and a strong alternative (strongest defensible reading).
- [ ] **Alternative Measurability Principle applied**: Each alternative interpretation is demonstrably more reasonable than the current version — "super-strong versions" that no text supports are not constructed, per the Quality Criteria.
- [ ] **Alternative distances annotated**: Each alternative is annotated with its distance from the original text (Small / Medium / Large), with justification for any stretching required.
- [ ] **Impact of substitution assessed**: For each alternative, how the argument's overall strength would change if the alternative were adopted is explicitly stated.
- [ ] **Holistic structural alternatives considered**: Beyond individual premises, whether alternative overall argument structures better reflect the author's intended reasoning is assessed — per the Holistic Structural Charity Assessment.

## Dialectical Fairness

- [ ] **Opposing positions accurately represented**: If the reconstructed argument addresses opposing positions, those positions are represented as their proponents would accept — not caricatured or weakened.
- [ ] **Argument presented at its strongest before critique**: Per the methodological foundations, the argument's claims are presented at their strongest defensible version before any criticism is applied.
- [ ] **Interpretive vs. critical charity distinguished**: The audit clearly separates being charitable in interpretation (constructing the strongest version) from being charitable in criticism (critiquing the strongest version) — both are checked.
- [ ] **Authorial contradictions noted, not forced**: If the author's views across texts are contradictory, the conflict is noted rather than the reconstruction being forced into a false consistency — per the Boundary Conditions.
- [ ] **Dialectical context respected**: The reconstruction reflects the debate context the author is engaged in — premises are not detached from the interlocutor they were designed to address.

## Report Quality

- [ ] **Executive summary present**: A one-paragraph overview covers audit status (Pass / Partial Pass / Fail), charity violation count, most critical issue, and key recommendation.
- [ ] **Premise-level table complete**: The charity assessment table includes Original Expression, Reconstructed Version, Charity Rating, and Issue Description for every premise — no premise skipped.
- [ ] **Violation details substantive**: Each charity violation includes Original Expression, Reconstructed Version, Problem description, Alternative Interpretations (with distances), and Impact of Substitution.
- [ ] **Holistic structural assessment included**: The overall argument structure is assessed for fidelity to authorial intent (Yes / Partial / No) with explanation.
- [ ] **Recommendations actionable**: Strengthening suggestions are specific and implementable — not merely gestural ("be more charitable").
- [ ] **Improvement directions clear**: The summary identifies concrete steps to bring the reconstruction into compliance with the Principle of Charity.
