# Abduction / Inference to the Best Explanation (IBE)

## Form

### Basic Abduction

```
[1] O          (Phenomenon O is observed)
[2] E → O      (If hypothesis H were true, O would be explained)
∴ [3] H        (Therefore, H is true -- as the explanation of O)
```

> Note: This is the **initial form**. As basic abduction it does not incorporate the dimension of comparison among competing hypotheses, and thus has weaker logical force.

### Inference to the Best Explanation (Complete Form)

```
[1] O             (The phenomenon to be explained)
[2] {H₁, H₂, …, Hₙ}    (Set of competing hypotheses)
[3] H₁ possesses superior explanatory power over H₂…Hₙ   (evaluated by the criteria below)
∴ [4] H₁          (Therefore, H₁ is the best explanation)
```

## Evaluation Criteria (Lipton, 2004; Harman, 1965)

| Criterion | Description | Philosophical Controversy |
|-----------|-------------|---------------------------|
| **Explanatory Power** | The range of phenomena the explanation covers | How to avoid overfitting |
| **Simplicity / Parsimony** | The fewest entities / principles postulated | Whether simplicity is a mark of truth |
| **Consistency** | Consistency with existing background knowledge | The problem of conservative bias |
| **Conservatism** | Minimal revision to existing theories | Same as above |
| **Testability** | Ability to generate new verifiable predictions | Prediction vs. postdiction |
| **Unification** | Unifying explanation across disparate domains | Whether unification equals truth |

## Typical Use Cases in Philosophical Analysis

- **Theory choice**: Realism vs. anti-realism -- which better explains scientific practice.
- **Other minds**: Analogical inference vs. inference to the best explanation.
- **The external world**: The best explanation of sensory experience.
- **Moral facts**: Whether moral realism provides the best explanation of moral disagreement.
- **Causal claims**: The best explanation of regularities (Humean vs. Anti-Humean).

## Reconstruction Hints

- IBE reasoning does not necessarily appear in complete form in the text. Often only H₁ → O is given, omitting comparison with H₂…Hₙ.
- **Reconstruction task**: Explicitly list the space of competing hypotheses -- even if the original text does not literally do so.
- Annotate how much comparison the author actually performs (which hypotheses the original text compares, and which it omits).

## Common Misuses

1. **False dichotomy**: Comparing only two hypotheses, ignoring a third possibility.
2. **Post hoc ergo propter hoc**: Temporal sequence mistaken for an explanatory relation.
3. **Circular explanation**: The hypothesis itself requires explanation of the same order.
4. **Tyranny of simplicity**: Assuming without argument that the simplest is true.
