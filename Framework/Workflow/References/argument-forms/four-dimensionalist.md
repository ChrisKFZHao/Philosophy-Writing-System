# Four-Dimensionalist Argument

## Form

### Core Structure — Argument from Temporary Intrinsics

```
[1] Objects have temporary intrinsic properties — they change over time in how they
    intrinsically are (e.g., a poker is bent at t1, straight at t2)
[2] If objects persist by enduring — i.e., are wholly present at each moment of their
    existence — then the very same object possesses the intrinsic property of being
    bent at t1 and the intrinsic property of being straight at t2
[3] But no object can possess incompatible intrinsic properties (being bent and being
    straight) without qualification
[4] Temporal qualification ("at t1" vs. "at t2") does not resolve the contradiction
    if the object is wholly present and intrinsically characterized at each time
∴ [5] Objects do not persist by enduring
    [6] Objects persist by perduring — i.e., they have distinct temporal parts at
        different times; one temporal part is bent, another temporal part is straight
    ∴ [7] Four-dimensionalism is true: objects are spacetime worms
```

### Argument from Vagueness (Sider)

```
[1] If composition were restricted (not universal), then there would be vague
    composition — borderline cases where it is indeterminate whether some xs compose a y
[2] Vague composition entails vague existence
[3] Vague existence is impossible (existence cannot be vague)
∴ [4] Composition is universal (unrestricted mereological composition)
    [5] If composition is universal, then four-dimensionalism follows (the
        four-dimensionalist can accept unrestricted composition without paradox)
```

### Argument from the Problem of Coincident Objects

```
[1] Endurantism has difficulty accounting for coincident objects — e.g., the statue and
    the lump of clay that coincide at all times but differ in modal properties
[2] Four-dimensionalism handles coincident objects naturally: coinciding objects share
    temporal parts at overlapping intervals but are distinct four-dimensional wholes
∴ [3] Four-dimensionalism provides a superior account of material constitution
```

## Distinctive Features

1. **Temporal parts as the key innovation**: Four-dimensionalism posits that objects extend through time in the same way they extend through space — as aggregates of temporal parts. The perdurance/endurance distinction is the metaphysical heart of the view.

2. **Solution by reification**: The argument resolves the problem of temporary intrinsics not by denying change, nor by explaining it away, but by reifying temporal stages as distinct entities. The cost is ontological: temporal parts must be accepted as real.

3. **Stage theory vs. worm theory**: Within four-dimensionalism, a further distinction exists:
   - **Worm theory** (Lewis): Ordinary objects are four-dimensional spacetime worms — the mereological sum of all temporal parts.
   - **Stage theory** (Sider): Ordinary objects are instantaneous temporal stages; persistence is a matter of counterpart relations between stages.

4. **Adverbialism as an alternative**: Haslanger and Johnston defend an adverbialist response: objects possess properties in a temporally modified way — "bent-ly at t1" and "straight-ly at t2" — without temporal parts. The adverbialist accepts endurantism but denies that incompatible properties are predicated of the object simpliciter.

## Evaluation Criteria

1. **The coherence of endurance**: Can the endurantist explain change without contradiction? Candidates include: temporalized property possession (adverbialism), relational rather than intrinsic properties (the relationist strategy), and presentism (only present objects and properties exist).

2. **Intrinsic vs. relational properties**: Is the four-dimensionalist forced to treat all seemingly intrinsic properties as relations to times? If so, the view may not preserve genuine intrinsic change.

3. **Persistence conditions**: What unifies temporal parts into a single persisting object? The four-dimensionalist needs an account of the unity relation (often: causal continuity, spatiotemporal continuity, or psychological continuity for persons).

## Famous Cases

| Argument | Proponent | Core Move |
|----------|-----------|-----------|
| Temporary Intrinsics | Lewis (1986) | Endurance → contradiction; perdurance resolves it |
| Vagueness Argument | Sider (2001) | Vague composition impossible; universalism → four-dimensionalism |
| Rotating Homogeneous Disc | Kripke/Armstrong | Disc rotating in empty space — no intrinsic change in temporal parts → problem for four-dimensionalism |
| Statue and Lump | Gibbard (1975) | Coincident objects favor four-dimensionalism |
| Time Travel and Self-Visitation | Lewis (1976) | A time traveler can meet herself → two temporal parts of the same person at the same time |

## Reconstruction Notes

- When reconstructing the argument from temporary intrinsics, two implicit premises are crucial: `[IP] Change requires that numerically the same object possess incompatible properties` and `[IP] Temporal qualification alone does not block contradiction for intrinsic properties`.
- Identify whether the argument targets **endurantism** directly (Lewis's strategy) or provides **positive grounds** for four-dimensionalism (Sider's strategy). The dialectical burden differs.
- Distinguish the **semantic** issue (how to analyze "a is bent at t") from the **metaphysical** issue (what the world must be like for such predication to be true). Many endurantist responses operate at the semantic level.
- Note whether the author is a **worm theorist** or **stage theorist** — the two versions of four-dimensionalism have different implications for persistence and counting.
