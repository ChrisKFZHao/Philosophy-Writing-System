# Modus Tollens (Denying the Consequent)

## Form

```
[1] P → Q    (If P, then Q)
[2] ¬Q       (Not-Q)
∴ [3] ¬P     (Therefore, not-P)
```

## Description

Modus tollens is a valid form of inference that derives the negation of the antecedent from a conditional statement and the negation of its consequent.

## Typical Use Cases in Philosophical Analysis

- **The converse of reductio arguments**: To refute a theory T (which entails some prediction P), one needs to establish ¬P.
- **Falsification inference**: A specific assertion derived from a universal principle turns out to be false → the principle itself does not hold.

## Common Variations

### Proof by Contradiction (Reductio Form)

```
[1] P → (Q ∧ ¬Q)    (P entails a contradiction)
[2] ¬(Q ∧ ¬Q)        (A contradiction cannot be true)
∴ [3] ¬P             (Therefore, not-P)
```

This form is equivalent to reductio ad absurdum.
