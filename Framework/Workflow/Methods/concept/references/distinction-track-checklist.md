# Distinction Tracking Quality Checklist

> After each distinction-tracking analysis, check each item. A fully checked list indicates a high-quality distinction tracking report.

---

## Distinction Detection & Extraction

- [ ] **Explicit distinctions exhaustively captured**: All explicitly marked distinctions (using "vs.," "not-X but Y," "in the sense of..., not...") in the text have been located and logged with textual evidence.
- [ ] **Implicit distinctions flagged**: Distinctions that the text relies on without stating explicitly are identified and annotated as "implicit," with the inferential basis for detection provided.
- [ ] **Distinction vocabulary scan complete**: Distinction-signaling language — "on the one hand/on the other hand," "by contrast," "differs from," "unlike," "whereas" — has been systematically scanned, not just obvious "X vs. Y" pairs.
- [ ] **No false positives**: Contrasts that are merely rhetorical or stylistic (not carrying argumentative work) are not classified as distinctions. Purely narrative contrasts are excluded.
- [ ] **Pole count correct**: For each distinction, the correct number of poles is identified — binary distinctions are not miscounted as trichotomies, and multi-way distinctions are not forced into a dichotomy.

## Distinction Typology & Classification

- [ ] **Type correctly assigned**: Each distinction is classified as Dichotomy, Trichotomy, Polytomy, Scalar, or Hierarchical, with a brief justification for the classification.
- [ ] **Exhaustiveness claim tested**: If a distinction is presented as exhaustive (claiming to cover all possibilities), the analysis actively tests whether there are genuinely no further possibilities — exhaustiveness is not accepted by default.
- [ ] **Mutual exclusivity verified**: For each distinction, whether the distinguished classes are mutually exclusive is assessed — overlap or borderline cases are flagged.
- [ ] **Hard vs. standpoint distinction flagged**: Following Stoljar (2010), whether the distinction is a "hard distinction" (reflecting real structure) or a "standpoint distinction" (reflecting a perspective) is assessed where relevant.
- [ ] **Natural-joint vs. artificial-line assessed**: Following the theory of distinctions, whether the distinction "carves at the joints" or is a pragmatic line drawn for convenience is evaluated.

## Function Analysis

- [ ] **Function type correctly classified**: Each distinction's argumentative function is classified as Clarificatory, Refutational tool, Defensive tool, Argument-space partitioning, or Definitional aid — with justification grounded in the text.
- [ ] **Function-argument linkage clear**: For each distinction, the specific argumentative step it serves is identified — the analysis does not merely name the function type but shows how the distinction does the work.
- [ ] **Consequence-of-absence assessed**: For each distinction, what would happen to the argument if the distinction were absent is considered — would a premise collapse? Would a fallacy go undetected?
- [ ] **Ad hoc distinctions flagged**: Defensive distinctions that appear to be introduced solely to except a counterexample (rather than independently motivated) are explicitly flagged as potentially ad hoc.
- [ ] **Definitional aid distinctions tested**: Distinctions used to define a concept by contrast are checked for whether the contrast actually illuminates the concept or merely restates it.

## Consistency & Drift Detection

- [ ] **Drift tested across all occurrences**: For each distinction, every occurrence across the text is compared — not just the first and last. Partial drift at intermediate steps is captured.
- [ ] **Shift type identified**: Where drift is detected, the type of drift is classified — boundary shift (the dividing line moves), criterion shift (the basis of distinction changes), or concept substitution (the distinguished concepts themselves change).
- [ ] **Equivocation risk assessed**: If the same term receives different distinction criteria at different argumentative stages, whether this produces an equivocation fallacy is explicitly assessed.
- [ ] **Drift at argumentatively critical points flagged**: Even small conceptual drift at key inferential steps is highlighted — as the Quality Criteria state, drift at critical junctures can be amplified into argumentative error.
- [ ] **Stable distinctions noted**: Distinctions that remain entirely consistent across the text are positively noted, not taken for granted.

## Network Mapping

- [ ] **All pairwise relations analyzed**: Each pair of distinctions has been checked for parallel, nested, or colliding relations.
- [ ] **Nesting depth tracked**: When one distinction is nested inside another, the nesting hierarchy is correctly represented — genus-species relations are not inverted.
- [ ] **Collisions explicitly diagrammed**: Where two distinctions intersect in application and produce unclear or contradictory categories, this collision is explicitly described with examples.
- [ ] **Network diagram clear**: The distinction network diagram (text-based) correctly represents all relations — parallel, nested, and colliding — and is visually distinguishable.
- [ ] **Distinction clusters identified**: Where multiple distinctions form a coherent cluster (e.g., all serving the same argumentative goal), this clustering is noted.

## Missing & Superfluous Distinctions

- [ ] **Domain-standard omissions detected**: Distinctions that are standard in the debate's domain but absent from the text are identified, with an explanation of why their absence matters to the argument.
- [ ] **Argumentative defect assessed**: For each missing distinction, whether the omission constitutes a genuine argumentative defect (rather than a mere stylistic choice) is evaluated.
- [ ] **Superfluous distinctions flagged**: Distinctions that are drawn but perform no argumentative work — or that overcomplicate the argument without gain — are identified. As the Quality Criteria state, "distinctions are not the more the better."
- [ ] **Omission impact graded**: The impact of each missing distinction on the argument is rated (Critical / Significant / Minor), not just listed.

## Report Quality

- [ ] **Executive summary present**: A one-paragraph overview covers total distinction count, key function types, most significant drift or collision, and most critical missing distinction.
- [ ] **Distinction inventory table complete**: The inventory table includes ID, Concept A vs. B, Type, Exhaustiveness, Mutual Exclusivity, and Location for every distinction.
- [ ] **Function analysis substantive**: For each distinction, the function analysis goes beyond labeling — it explains the argumentative role and the consequence if the distinction were absent.
- [ ] **Consistency table present**: The consistency/drift check table covers every distinction with specific issue descriptions where drift is detected.
- [ ] **Overall assessment actionable**: The final assessment identifies the 2-3 most significant issues (drift, collision, omission) and explains their argumentative significance.
