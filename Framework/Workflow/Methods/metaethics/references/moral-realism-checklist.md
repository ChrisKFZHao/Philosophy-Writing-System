# Moral Realism Argument Analysis Quality Checklist

> After each moral realism argument analysis, check each item. A fully checked list indicates a high-quality analysis.

---

## Position Spectrum Classification

- [ ] **Spectrum precision achieved**: Is the position classified to the most specific category on the realism spectrum (e.g., "quasi-realist expressivism" not "non-cognitivism")?
- [ ] **Textual evidence cited**: Does each classification claim cite specific stance markers (cognitivist, non-cognitivist, realist, anti-realist, error-theoretic, constructivist) from the source or reconstruction?
- [ ] **Ambiguity handled correctly**: If ambiguous between two positions, is the diagnostic question articulated that would resolve it? If ambiguous between non-adjacent positions, are both presented as live possibilities with distinguishing evidence?
- [ ] **Pre-1903 texts annotated**: If the source predates contemporary metaethics terminology, has the historical distance been explicitly noted?

## Commitment Dimension Assessment

- [ ] **All four dimensions assessed**: Are stances documented for cognitivism, truth-status, mind-independence, and existence of moral facts?
- [ ] **Explicit vs. implicit marked**: Is each commitment designated as explicitly stated in a premise or implicitly required by the argument's structure?
- [ ] **Textual traceability maintained**: Can every commitment attribution be traced to a specific premise or passage?
- [ ] **Cross-commitment consistency checked**: Have semantic, metaphysical, and psychological commitments been checked for mutual consistency (e.g., Smith's moral problem — cognitivism + internalism + Humeanism yields inconsistency)?

## Vulnerability Detection

- [ ] **All applicable challenges evaluated**: Have all seven canonical challenges (Queerness, Disagreement, Supervenience, Frege-Geach, Evolutionary Debunking, Open Question, Moral Twin Earth) been assessed for applicability?
- [ ] **Ratings calibrated to argument**: Are vulnerability ratings based on the specific argument's resources (not just the position in general)? A robust realist argument that addresses queerness should rate lower than one that ignores it.
- [ ] **Response resources identified**: For each challenge, has the report assessed whether the argument has explicit or implicit resources for response?
- [ ] **No dismissals by label**: Has the report avoided dismissing positions by their "counterintuitive" or "spooky" character and instead analyzed specific argument resources?

## Argument Evaluation

- [ ] **Argument-vs-position distinguished**: Does the report keep distinct: (a) what metaethical position the argument supports, and (b) whether the argument is structurally sound?
- [ ] **Positive and negative arguments separated**: Are the argument's positive case (what it affirms) and negative case (what it attacks) clearly distinguished and separately reconstructed?
- [ ] **Dialectical role classified**: Is the argument classified as first-order, second-order, or defensive?
- [ ] **Principle of charity applied**: Are rival positions presented in their strongest form?

## Distinction from Normative Ethics

- [ ] **Level conflation flagged**: If the argument slides between metaethical claims (about the status of morality) and normative claims (about what is morally required), has this been flagged?
- [ ] **Pure normative text identified**: If the text contains only first-order normative claims without metaethical argument, has the analysis identified this (per boundary condition 2)?
- [ ] **No metaethical content handled**: If no metaethical stance markers are present, has the analysis reported "No metaethical arguments detected" (per boundary condition 1)?

## Report Quality

- [ ] **Commitment transparency**: Are the four core dimensions documented with explicit/implicit designation and evidence for each?
- [ ] **Counter-positions well-chosen**: Are the recommended counter-positions (2-4) selected for maximum dialectical pressure on the argument's weakest specific commitment?
- [ ] **Spectrum position map clear**: Does the map show adjacent positions and fault lines that separate them from the classified position?
- [ ] **Dialectical fairness maintained**: Has the report treated rival positions respectfully and analyzed them on their own terms?
