# Moral Psychology Analysis Quality Checklist

> After each moral psychology analysis, check each item. A fully checked list indicates a high-quality analysis.

---

## Internalism/Externalism Classification

- [ ] **Precision of classification**: Is the position classified with the correct strength level (strong/weak/rational/externalist), not merely "internalist"?
- [ ] **Textual evidence**: Is each classification supported by explicit quotation or premise reference from the source argument?
- [ ] **Confidence annotation**: Is the confidence level (high/medium/low) explicitly stated and justified?
- [ ] **Amoralist status**: Is the amoralist's status under the classified view (conceptually impossible/possible but abnormal/possible but irrational/fully possible) explicitly identified?
- [ ] **Tension flagging**: Are any internal tensions in the argument's position (e.g., asserting strong internalism but accommodating the amoralist) flagged and discussed?

## Amoralist Test

- [ ] **Precise characterization**: Is the amoralist characterized with all four features (sincere judgment, full comprehension, no motivation, possibility of counter-motivation)?
- [ ] **Handling assessment**: Is the argument's handling of the amoralist (or its silence) explicitly assessed for each of the four internalism/externalism positions?
- [ ] **Plausibility evaluation**: Is the plausibility of the argument's amoralist handling independently evaluated, not merely reported?
- [ ] **Burden assignment**: Are the dialectical burdens created by the argument's amoralist handling (or non-handling) explicitly identified?
- [ ] **Inverted-commas check**: If the argument uses the "inverted commas" strategy to dismiss the amoralist, is its adequacy critically assessed?

## Humean/Anti-Humean Diagnosis

- [ ] **Framework classification**: Is the argument's theory of motivation explicitly classified (humean/anti_humean/hybrid/not_specified)?
- [ ] **Direction-of-fit analysis**: If the argument uses direction-of-fit language, is it correctly identified and analyzed?
- [ ] **Default awareness**: If the argument is silent on the Humean theory, is the Humean default noted and the argument assessed against it?
- [ ] **Interaction mapping**: Is the interaction between the Humean/anti-Humean classification and the internalism/externalism classification explicitly traced (the "Moral Problem" trilemma)?
- [ ] **Implicit commitment detection**: Are implicit Humean or anti-Humean commitments (e.g., assuming belief-desire psychology without argument) flagged?

## Akrasia Analysis

- [ ] **Precise characterization**: Is akrasia characterized with all key features (all-things-considered judgment, free intentional contrary action, awareness at time of action)?
- [ ] **Sufficiency/contributory distinction**: Is the crucial distinction between motivation as sufficient for action versus contributory explicitly addressed?
- [ ] **Empirical adequacy**: Is the view explicitly assessed for whether it makes akrasia impossible, implausibly rare, or fully accommodated?
- [ ] **Phenomenological fit**: Does the analysis check whether the view captures the phenomenology of akrasia (it feels like a failure, not a mere preference shift)?
- [ ] **Tension flagging**: If the view precludes akrasia entirely, is this flagged as a significant empirical problem?

## Motivation Direction Assessment

- [ ] **Direction-of-fit annotation**: Are the directions of fit (mind-to-world for belief, world-to-mind for desire/emotion) correctly assigned to each state in the motivational architecture?
- [ ] **Causal/rational chain**: Is the "because" chain from moral judgment through motivation to action explicitly diagrammed?
- [ ] **Completeness**: Are all relevant states (judgment, belief, desire, emotion, intention, action) represented in the architecture map?
- [ ] **Contingent vs. necessary links**: Are the links in the motivational chain correctly marked as necessary or contingent according to the argument's commitments?
- [ ] **Architecture consistency**: Is the motivational architecture map consistent with the internalism/externalism and Humean/anti-Humean classifications?

## Metaethical Implications

- [ ] **Trilemma application**: If the argument's commitments fit the "Moral Problem" trilemma, is it explicitly analyzed in those terms?
- [ ] **Compatible positions**: Are all metaethical positions compatible with the argument's moral psychology explicitly listed?
- [ ] **Incompatible positions**: Are all metaethical positions ruled out by the argument's moral psychology explicitly listed?
- [ ] **Inferential chain explicitness**: Is the full inferential chain from psychology to metaethics shown, not merely asserted?
- [ ] **Consistency check**: Are any inconsistencies between the argument's moral psychology and its explicit metaethical commitments flagged?

## Report Quality

- [ ] **Schema compliance**: Does the report conform to the six-section structure (Internalism/Externalism, Humean/Anti-Humean, Amoralist, Akrasia, Architecture, Implications)?
- [ ] **Executive summary**: Does the executive summary concisely state the classified position and key implications?
- [ ] **Idiom neutrality**: Is the report free of evaluative idioms that presuppose a position (e.g., "the argument correctly identifies")?
- [ ] **Boundary handling**: If the argument contains no motivational claims, does the report note this and offer implicit analysis where appropriate?
- [ ] **Downstream signaling**: Are the implications for downstream skills (method.metaethics.moral-realism, method.metaethics.moral-semantics) noted where relevant?
