# Philosophical Methodology Analysis Quality Checklist

> After each methodology analysis, check each item. A fully checked list indicates a high-quality analysis.

---

## Explicit Signal Detection
- [ ] **Overt declarations located**: Have all explicit methodological statements in the text been identified and documented with textual locations?
- [ ] **Genre signals assessed**: Have genre-based methodological signals (formal structure, experimental design, first-person phenomenology, historical narrative) been evaluated?
- [ ] **Tradition-identification signals noted**: Has the author's self-identification with a philosophical tradition been noted, along with its methodological implications?
- [ ] **Signal-tension flagged**: If explicit signals conflict with each other or with the argument's actual operation, has this tension been identified?

## Implicit Commitment Identification
- [ ] **Evidential basis examined**: Has the argument's de facto treatment of evidence been analyzed?
- [ ] **Inferential patterns mapped**: Have characteristic inference forms been identified and linked to methodological commitments?
- [ ] **Refutation standards inferred**: Has what would count as refuting the argument been used to infer its methodological commitments?
- [ ] **Objection-treatment analyzed**: Has how the argument handles objections revealed its methodological assumptions?
- [ ] **Confidence levels annotated**: Is each implicit commitment accompanied by a confidence level (high/medium/low)?

## Method Classification
- [ ] **Taxonomy applied correctly**: Does each detected method map cleanly onto the standard taxonomy, with specific features cited?
- [ ] **Absent features noted**: Have absent-but-characteristic features been identified for each classification?
- [ ] **Hybrid or modified use flagged**: If a method is used in non-canonical form, has the modification been characterized?
- [ ] **Multi-method relationships characterized**: Are relationships among multiple methods (complementary, competing, nested, juxtaposed) clearly stated?
- [ ] **Classification resistance documented**: If the argument resists classification, has the reason been articulated?

## Methodological Consistency Check
- [ ] **Method-switching detected**: Has unacknowledged switching between methods at critical junctures been identified?
- [ ] **Evidential-standards consistency**: Are the same evidential standards applied to claims throughout the argument?
- [ ] **Scope-expansion checked**: Do any conclusions exceed what the method that generated them can support?
- [ ] **Internal-norm violations**: Has the argument's adherence to the norms internal to its own method been assessed?

## Method-Argument Fit
- [ ] **Strengths-alignment assessed**: Are the method's distinctive strengths aligned with the argument's epistemic goals?
- [ ] **Limitations-relevance evaluated**: Are the method's characteristic limitations relevant to this specific argument's subject matter?
- [ ] **Subject-matter resistance considered**: Has the question been examined for features that resist the chosen method?
- [ ] **Conclusion-kind match**: Does the method deliver conclusions of the right kind and generality for the argument's aims?

## Limitation Assessment
- [ ] **Structural limitations catalogued**: Have the constitutive limitations the method cannot overcome been identified?
- [ ] **Scope limitations specified**: Has the domain within which the method's results are valid been delineated?
- [ ] **Idealization gap assessed**: Has the gap between simplified models and the phenomena they model been evaluated?
- [ ] **Implementation vs. structural distinguished**: Have contingent execution failures been distinguished from constitutive limits?
- [ ] **Fatal/restrictive/benign classified**: Has each limitation been classified by its impact on the argument?

## Alternative Methods Consideration
- [ ] **Multiple alternatives examined**: Have at least two or three major methodological alternatives been considered?
- [ ] **Divergence points identified**: Have specific argumentative steps where method makes a difference been identified?
- [ ] **Convergence/divergence estimated**: Has the likely direction and magnitude of divergence been assessed with justification?
- [ ] **Underdetermination assessed**: Has the extent to which the methodological choice is underdetermined by the argument's aims been evaluated?
- [ ] **Literature-grounded comparisons**: Are comparisons grounded in actual applications in the literature?

## Report Quality
- [ ] **Comprehensiveness**: Does the report detect all major methodological commitments, implicit and subsidiary?
- [ ] **Evidence-grounding**: Is every methodological attribution supported by specific textual or structural evidence?
- [ ] **Fairness to author**: Does the report consider charitable resolutions of apparent tensions?
- [ ] **Actionable insight**: Does the report explain why methodological choices matter for the argument's success or failure?
- [ ] **Reflexive awareness**: Does the report acknowledge its own methodological commitments?
