# Essentialist Claim Detection Quality Checklist

> After each essentialist claim analysis, check each item. A fully checked list indicates a high-quality analysis.

---

## Essence Claim Extraction

- [ ] **Exhaustive language scan**: Are all instances of essentialist language detected — explicit terms ("essentially," "by nature," "in virtue of what it is"), modal terms used essentialistically ("necessarily has"), and implicit commitments (sortal predication, kind identity, persistence claims)?
- [ ] **Entity disambiguation**: Is each entity (individual, kind, property, concept) correctly identified and disambiguated? E.g., "water" as kind vs specific sample.
- [ ] **Property specification**: Is each claimed essential property articulated as a precise, complete predicate — not a vague phrase?
- [ ] **Scope classification**: Is each claim correctly classified as individual essence, kind essence, property essence, or conceptual essence?
- [ ] **Structural role assignment**: Is each claim correctly tagged as direct premise, inferred conclusion, suppressed premise, or background framework?
- [ ] **Confidence coding**: Are explicit and implicit claims coded by detection confidence (explicit, implicit-medium, implicit-low) with justification for implicit claims?

## Modal/Non-Modal Distinction

- [ ] **Essence-vs-necessity distinction**: Does the analysis maintain a clear distinction between "X is necessarily F" (modal) and "X is essentially F" (essentialist), even when the argument conflates them?
- [ ] **De re / de dicto classification**: Is each claim correctly classified as de re (about the thing) or de dicto (about the statement)? De re essentialism is flagged as more metaphysically weighty.
- [ ] **Modal system specification**: Is the required modal logic (K, T, S4, S5, B) specified and justified for each essentialist claim?
- [ ] **Cross-world identification diagnosed**: For de re claims about individuals, is the mechanism of cross-world identification (rigid designation, counterpart theory, haecceities, origin essentialism) diagnosed from the argument's commitments?

## Fine's Test Application

- [ ] **Necessity check**: For each essentialist claim, is it determined whether the property is necessary (had in all worlds where the entity exists)?
- [ ] **Singleton-set test**: Is it determined whether each necessary property is a trivial logical consequence (like set-membership or logical-truth properties) or a substantive, definitional property?
- [ ] **Definitional test**: Does the property tell us what the entity is — would it figure in a plausible real definition?
- [ ] **Grounding-direction test**: Does the property explain other properties (mark of essentiality), or is it explained by them (mark of non-essentiality)?
- [ ] **Finean assessment rating**: Is each claim rated as genuinely essential, merely necessary, neither necessary nor essential, or indeterminate?
- [ ] **Overgeneration flagging**: If the argument conflates necessity and essence (treating all necessary properties as essential), is this conflation prominently flagged?

## Framework Consistency

- [ ] **Framework diagnosis with evidence**: Is the essence framework (modal, definitional, constitutive, sortal, scientific, nominal) diagnosed with specific evidence (explicit commitment or diagnostic inference from the argument's inferential patterns)?
- [ ] **Framework-switching detection**: If the argument draws on multiple frameworks inconsistently (e.g., Kripkean language for the claim, Finean language for the conclusion), is the inconsistency flagged?
- [ ] **Humean/Anti-Humean classification**: Is the argument classified on the Humean/anti-Humean axis, with justification? (Modal essentialism is broadly Humean; definitional, constitutive, sortal, and scientific essentialism are anti-Humean.)
- [ ] **Inference-direction check**: Does the argument infer modality from essence (definitional/sortal/scientific frameworks) or essence from modality (modal framework)? Is the direction consistent with the diagnosed framework?

## Essential/Accidental Demarcation

- [ ] **Persistence-condition alignment**: If the argument draws essence/accident distinctions through persistence-through-change reasoning, is the alignment between essential properties and survival conditions checked?
- [ ] **Artifact vs natural kind treatment**: If the argument concerns artifacts, is the special status of artifact essences (contested, possibly nominal) acknowledged?
- [ ] **Normative essentialism flagging**: If the argument makes essentialist claims about normatively laden kinds ("persons essentially have moral worth"), is the slide from descriptive to normative flagged?
- [ ] **Boundary case handling**: If the essence/accident boundary is genuinely indeterminate for the entity in question, is this acknowledged rather than having a forced classification imposed?

## Challenge Assessment

- [ ] **Fine's objection applied**: Is Fine's modal objection assessed for each claim — are there necessary-but-not-essential properties in the argument's ontology that the modal criterion would misclassify?
- [ ] **Contingent essence check**: Is the possibility of essential-but-not-strictly-necessary properties (Fine's "too narrow" prong) assessed?
- [ ] **Epistemological gap identified**: If the argument asserts essentialist claims without accounting for how they are known, is the epistemological gap flagged?
- [ ] **Quine's challenge addressed**: Does the argument's de re essentialism survive Quine's referential opacity challenge? Does it rely on rigid designation? Is this reliance acknowledged?
- [ ] **Nominalist challenge addressed**: If the argument assumes realism about kinds or properties, is the nominalist alternative considered?

## Report Quality

- [ ] **Structured format**: Does the report follow the standard structure (Essentialist Claim Catalog, Framework Diagnosis, Modal Profile, Challenge Assessment, Alternative Frameworks, Dialectical Implications)?
- [ ] **Evidence grounding**: Is every diagnostic claim supported by specific evidence from the argument?
- [ ] **Boundary conditions respected**: If no essentialist language is detected, is the analysis declined? If only modal language (without essentialist commitment) is present, are de dicto and de re readings distinguished?
- [ ] **Historical context**: If the argument is from a pre-Kripkean text (Aristotelian, Scholastic), is the historical framework accurately diagnosed, and is the argument additionally assessed under contemporary frameworks without anachronism?
- [ ] **Alternative framework evaluation**: Are the major alternative essence frameworks evaluated for each central claim, with specific reasoning about whether the claim survives reinterpretation?
