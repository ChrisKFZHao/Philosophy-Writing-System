# Argument Reconstruction Report Template

Template for `phil-argument-reconstruct` output reports.

---

```
===============================================================================
论证重构报告：{Paper Title / Text Reference}
===============================================================================

日期：{YYYY-MM-DD}
原文：{Author, "Title"} (基于{阅读笔记/原文}重构)
重构者：phil-argument-reconstruct skill v{version}
===============================================================================


0. 原文背景
-------------------------------------------------------------------------------

{1-2 paragraphs: the text's main thesis, argumentative strategy, and
intellectual context. What is the author trying to establish? What is the
dialectical situation the text intervenes in?}


1. 论证一：{Argument Name / Descriptive Label}
===============================================================================

### 基本信息
- 论证编号：{AUTHOR-ARG-01}
- 论证类型：{deductive / inductive / abductive / analogical / transcendental / dilemma / reductio / definitional / practical / modal}
- 逻辑形式：{One-line description of the argument's logical structure}
- 原文来源：{Section / paragraph reference}

### 前提-结论结构

[P1] {First explicit premise}
[P2] {Second explicit premise}
...
───────
[C1] ∴ {Conclusion}

### 隐含前提

[IP1] {Implicit premise description}
      （确定性: {high / medium / low} —— {Justification for certainty rating}）

[IP2] ...

### 结构评估

{1-2 paragraphs: Is the argument structurally valid? What are the key
controversial premises? What would an opponent reject?}


2. 论证二：{Argument Name}
===============================================================================

{Same structure as Argument 1}


N. 总体辩证结构
===============================================================================

{ASCII tree diagram showing how arguments relate:
- Which arguments support which conclusions?
- Which arguments are independent vs. serial?
- What is the overall argumentative architecture?}


N+1. 关键评估
===============================================================================

N+1.1 论证力度

{Assessment of overall argumentative strength. Which arguments are strongest?
Which are weakest? Where does the overall case depend on a single vulnerable
premise?}

N+1.2 主要挑战

{3-5 most significant challenges or vulnerabilities identified.}

N+1.3 为何这个论证很重要

{1 paragraph: What is the philosophical significance? What debate does it
advance? What would change if it succeeds?}

===============================================================================
* 重构完成。本分析基于{原文/阅读笔记}。
* 引用时请标注原始论文：{Full citation}。
* 论证重构遵循 phil-argument-reconstruct v{version} 标准格式。
===============================================================================
```
